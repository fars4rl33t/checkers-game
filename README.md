# 🏁 Русские Шашки (Checkers Game)

Веб-версия классических русских шашек, разработанная на чистом HTML, CSS и JavaScript — без фреймворков, сборщиков и зависимостей.

---

## ✨ Основные возможности

- **Два режима игры** — «Игрок против Игрока» (2 игрока за одним экраном) и «Игрок против Компьютера» (бот с приоритетной логикой: обязательное взятие с максимальной серией → безопасный продвигающий ход → случайный ход).
- **Полное соблюдение правил русских шашек**:
  - обязательное взятие — если есть бой, простой ход недоступен;
  - серийное (множественное) взятие — фигура обязана продолжать бить, пока есть чем;
  - превращение в дамку «на лету» прямо в середине серии взятий, с немедленным переходом на длинные прыжки дамки;
  - «турецкий удар» — срубленная фигура остаётся на доске до конца хода и не может быть срублена повторно в том же ходу;
  - правило ничьей — 15 полуходов без взятия в эндшпиле «дамка против дамки».
- **Визуальные подсказки** — подсветка выбранной фигуры, доступных ходов и взятий, клеток последнего хода, координатная разметка (a–h, 1–8) по периметру доски.
- **Дашборд игроков** — имя, статус хода и графическое «кладбище» срублённых фигур для каждой стороны.
- **История ходов** в шашечной нотации (например, `1. e3-d4 d6-c5`).
- **Праздничное модальное окно победы** со статистикой партии и конфетти на `<canvas>`.
- **3 темы оформления** («Классическое дерево», «Неоновый Киберпанк», «Скандинавский минимализм»), сохраняются в `localStorage`.
- **Адаптивный дизайн** — доска и все панели корректно перестраиваются под мобильные экраны.

## 🚀 Как запустить

Сборка, установка зависимостей и локальный сервер не требуются — это чистый HTML/CSS/JS.

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/fars4rl33t/checkers-game.git
   ```
2. Откройте файл `index.html` в любом современном браузере (двойным кликом или через «Открыть файл»).

Готово — игра запускается сразу.

## 🛠️ Стек технологий

- **HTML5** — семантическая разметка, `<canvas>` для конфетти.
- **CSS3** — раскладка на Grid и Flexbox, CSS-переменные для системы тем, анимации и переходы.
- **Vanilla JavaScript** — вся игровая логика, DOM-рендеринг и ИИ бота без сторонних библиотек.
